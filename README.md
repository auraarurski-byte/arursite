# ArurHub V2

Elite Roblox Script Service — The Final Evolution.

## Stack

- **Next.js 14** (Pages Router)
- **React 18**
- **TypeScript**
- CSS Modules + CSS Variables

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

# ArurHub V2

**The Final Evolution** – A premium Roblox script service website built with Next.js and TypeScript.

## Features

- 🎨 Cyber-purple glassmorphism dark theme
- 🖥️ Interactive UI mockup (fully functional toggles, sliders, tabs)
- 🖼️ In-game gallery with SVG chroma-key filter
- 📱 Mobile-first responsive design
- ⚡ Scroll-reveal animations (no heavy libraries)
- 💰 Pricing tiers (Weekly / Monthly / Lifetime)
- ❓ FAQ accordion
- 🔢 Header with blur-glass scroll effect

## Stack

- [Next.js 14](https://nextjs.org/)
- [React 18](https://react.dev/)
- [TypeScript 5](https://www.typescriptlang.org/)

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy

Push to `main` — Vercel auto-deploys on every commit.
